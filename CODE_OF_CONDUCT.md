# Code of conduct

AttendEase is a small project made by and for students. Everyone taking part (in issues, pull
requests, discussions or reviews) is expected to:

- **Be respectful and patient.** People of every background, skill level and language are welcome.
- **Keep it about the work.** Criticise code and ideas, not people.
- **Protect privacy.** Never post anyone's attendance report, name, roll number, contact details or other personal information, your own included.
- **Assume good faith**, and help newcomers get started.

Not acceptable: harassment, insults, discriminatory language, sexual content, threats,
publishing someone's private information, or deliberately disruptive behaviour.

## Enforcement

The maintainers may edit or remove comments, close issues and pull requests, and block
accounts that break these rules. To report a problem privately, use the repository's
**Security → Report a vulnerability** form and say it's a conduct report. It will be handled
confidentially.

This code of conduct is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
